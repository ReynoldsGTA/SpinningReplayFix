# SpinningReplayFix

Fixes for the GTA: San Andreas replay system:

- Bike and BMX wheels spin (and suspension moves) in replays. Only works with replays recorded whilst this script is active.
- Vehicles generate sparks when scraping during replay playback. Collision runs on the replay state, which is then restored, so vehicles stay exactly on their recorded path.

## Download

[Download](https://github.com/ReynoldsGTA/SpinnngReplayFix/raw/main/SpinningReplay.SA.asi)

## Instructions

Put in the GAME_FOLDER/scripts folder and use your favourite ASI loader to load the script. 
For an ASI loader I recommend Silent's which you can find [here](https://gtaforums.com/topic/523982-relopensrc-silents-asi-loader/)
